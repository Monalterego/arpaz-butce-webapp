Bütçe Kurgusu — Nasıl Hesaplanıyor? ▸

1) Plan Stok % = ( Kâr%×W + Satış%×W + Stok%×W ) → 100'e normalize
2) Plan Stok Adet = ( Toplam Stok × Hedef Stok Büyümesi ) × Plan Stok %
3) Satış Bütçe = ( Plan Stok Adet ÷ Hedef Cover [elle] ) × Pazarlama Büyümesi × Çarpanlar
4) LFL = Bütçe/LY Satış−1 · R-LFL = (Bütçe/PlanStok)/(LY Satış/LY Stok)−1 · Stok Büyümesi = PlanStok/LY Stok−1
